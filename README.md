# Centurio

Персональная панель быстрого запуска приложений для Windows: живёт в трее,
открывается по клику или горячей клавише, показывает библиотеку программ и игр
плитками с иконками и постерами.

Написана на [Flet](https://flet.dev). Интерфейс — русский.

## Два окна

- **«Запуск»** — узкое окно по `Ctrl+Space` из любой программы: строка поиска,
  закреплённые плитки и список последнего. Набрал две буквы, `Enter` — окно
  ушло. Отдельные настройки не нужны, всё берётся из библиотеки.
- **«Библиотека»** — большое окно со всей коллекцией: рельса категорий слева,
  боковая панель с фильтрами, лента быстрого запуска, секции по категориям.
  Переключение между окнами — в заголовке или `Ctrl+L`.

## Возможности

- **Автопоиск установленного** — ярлыки меню «Пуск», ключи удаления и `App Paths`
  в реестре, библиотеки Steam (включая дополнительные диски) и манифесты Epic
  Games. Системные утилиты, деинсталляторы и распространяемые пакеты
  отфильтровываются. Найденное показывается группами по источнику, а не одним
  списком.
- **Разбор** — новое, что нашлось при сканировании, не сваливается в библиотеку,
  а встаёт в очередь. Экран разбора показывает по одной программе и предлагает
  категорию: `1`…`4` — положить, `Enter` — согласиться с предложенной, `→` —
  пропустить, `Del` — не нужна. Счётчик очереди виден на рельсе.
- **Наборы** — несколько программ, которые открываются одной кнопкой («Рабочее
  утро»). Набор можно закрепить в ленте быстрого запуска рядом с плитками.
- **Панель справа вместо диалогов** — клик по плитке открывает инспектор:
  категория, закрепление, горячая клавиша, параметры запуска. Модальных окон в
  программе нет ни одного, всё сохраняется само.
- **Правая кнопка** — контекстные меню на плитке, на выделении, на заголовке
  категории и на пустом месте сетки. Пересканирование и ручное добавление файла
  живут там.
- **Отмена вместо подтверждения** — удаление приложения, категории или набора
  происходит сразу, а внизу на восемь секунд появляется «Вернуть».
- **Иконки и постеры** — извлекаются из `.exe`, для игр берутся из кэша Steam,
  а если его нет — с CDN. Офлайн загрузка обложек отключается сама и включается
  обратно при явном пересканировании. Буквы вместо иконки не рисуются: если
  картинки нет, показывается значок категории.
- **Категории** — свои названия, цвета и иконки; цвет выбирается из палитры,
  hex-полем или двумя ползунками. Приложение переносится в категорию
  перетаскиванием на значок слева или пунктом «Переложить в…».
- **Быстрый запуск** — закреплённые плитки на `Ctrl+1`…`Ctrl+9` и произвольные
  глобальные горячие клавиши для любого приложения. Номер на плитке — это
  ровно та комбинация, которая её запускает.
- **Индикатор «Запущено»** — по имени процесса, работает и для игр, которые
  стартуют через `steam://` или `com.epicgames.launcher://`.
- **Параметры запуска** — аргументы, рабочая папка, запуск от администратора.
- **Спокойный вид** — один переключатель в настройках убирает счётчики, пути и
  подсказки клавиш, если они мешают.
- **Трей и автозапуск** — сворачивание/закрытие в трей, автостарт с Windows.
  В меню трея — последние программы, запускаются не открывая окна.

### Клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Space` | Показать или спрятать «Запуск» (меняется в настройках) |
| `Ctrl+1`…`Ctrl+9` | Запуск закреплённого приложения, из любой программы |
| `Ctrl+L` | Открыть библиотеку |
| `Ctrl+K` | Встать в строку поиска |
| `Ctrl+,` | Настройки |
| `Ctrl+A` | Выделить всё в сетке |
| `Delete` | Убрать выделенное (с «Вернуть») |
| `Ctrl+Enter` | Добавить отмеченное на экране «Найти и добавить» |
| Стрелки | Перемещение по плиткам и по списку в «Запуске» |
| `Enter` | Запуск выбранного |
| `Esc` | Снять по одному слою: меню, панель, поиск, экран |

На экране разбора: `1`…`4` — положить в категорию, `Enter` — согласиться с
предложенной, `→` — пропустить, `Del` — не нужна.

## Запуск из исходников

```bash
pip install -r requirements.txt
python main.py
```

Флаги и переменные окружения:

| | |
|---|---|
| `--hidden` | Старт свёрнутым в трей (используется автозапуском) |
| `--debug` или `CENTURIO_DEBUG=1` | Подробный лог в файл и в консоль |
| `CENTURIO_WEB=1`, `CENTURIO_PORT` | Открыть интерфейс в браузере вместо окна |

Веб-режим существует для отладки на не-Windows машине: трей, глобальные горячие
клавиши, автозапуск и поиск установленных программ в нём не работают.

## Где лежат данные

Всё в `%APPDATA%\Centurio\`:

| Файл | Что это |
|---|---|
| `centurio-data.json` | Библиотека, категории, наборы, очередь разбора, настройки |
| `icons\` | Кэш иконок и обложек |
| `centurio.log` | Лог (только в режиме `--debug`) |
| `centurio-backup-*.json` | Резервные копии (кнопка в настройках) |
| `centurio-corrupt-*.json` | Карантин повреждённого файла данных |

Файл данных версии 2. Библиотека версии 1 читается как есть: наборы и очередь
разбора добавляются пустыми, ничего не теряется.

## Тесты

```bash
python tests/test_centurio.py
```

Логика (хранилище, поиск приложений, цвета, запросы) проверяется на любой ОС и
без зависимостей; тесты интерфейса пропускаются, если Flet не установлен.

Часть тестов сторожит правила, а не поведение: в интерфейсе нет ни одного
`AlertDialog`, раскладка библиотеки осталась прежней, цвета берутся только из
`app/colors.py`, номер на плитке совпадает с горячей клавишей, а в текстах нет
символов, которых нет во вшитых шрифтах.

## Сборка Windows-инсталлятора

```bash
pip install "flet[all]==0.28.3"
python -m app.iconify                       # сгенерировать icon.png и tray.png
flet build windows -v                       # результат: build\windows\
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\centurio.iss
```

Готовый `installer\Output\CenturioSetup.exe` ставится без прав администратора и
предлагает создать ярлыки на рабочем столе и в автозапуске. То же самое делает
workflow **Build Windows installer** (вручную или по тегу `v*`).

Версия задаётся в `app/__init__.py`; `pyproject.toml` и `installer/centurio.iss`
должны совпадать с ней — это проверяется тестом.

## Диагностика

```bash
python -m app.diagnose
```

Печатает версию Python, состояние зависимостей, путь к файлу данных, результат
поиска приложений и найденные корни Steam — этот вывод удобно прикладывать к
сообщению о проблеме.
