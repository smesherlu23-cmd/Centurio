# Centurio

Персональная панель быстрого запуска приложений для Windows: живёт в трее,
открывается по глобальной горячей клавише и запускает программу за две секунды.

Написана на [Flet](https://flet.dev). Интерфейс — русский.

## Два режима

Программа — это одно окно с двумя разными режимами.

**«Запуск»** — компактное окно 720×520, которое открывается по `Ctrl+Пробел`.
Поле поиска в фокусе сразу, закреплённые программы под ним, ниже — наборы и то,
что открыто или запускалось недавно. Две буквы, `Enter` — и окно уходит в трей
само. Это 95 % работы с программой.

**«Библиотека»** — полное окно 1180×768, где программы добавляют, раскладывают
по категориям и настраивают. Открывается по `Ctrl+L` или переключателем в шапке.

Модальных окон нет ни одного: правка программы живёт в правой панели, категории
правятся поповером у их значка, «Найти и добавить» и «Настройки» — экраны внутри
окна, а результат действия и его отмена — в тосте снизу.

## Возможности

- **Автопоиск установленного** — ярлыки меню «Пуск», ключи удаления и `App Paths`
  в реестре, библиотеки Steam (включая дополнительные диски) и манифесты Epic
  Games. Найденное сгруппировано по источнику, каждой строке предлагается
  категория (Steam → «Игры», JetBrains → «Разработка», графика → «Творчество»),
  а уже добавленное помечено и не добавляется дважды.
- **Настоящие иконки** — извлекаются из `.exe`, для игр берутся обложки из кэша
  Steam, а если его нет — с CDN. Буквенных заглушек нет: если иконку получить не
  удалось, на её месте нейтральная площадка со значком категории.
- **Категории** — свои названия, палитра из восьми цветов и поиск иконки по
  названию. Программа переносится перетаскиванием на значок категории слева,
  порядок категорий — перетаскиванием самих значков.
- **Наборы** — несколько программ под одним именем («Рабочее утро»), запускаются
  одной плиткой в «Запуске»; собираются из выбранных плиток.
- **Быстрый запуск** — закреплённые плитки на `Ctrl+1`…`Ctrl+9` и произвольные
  глобальные горячие клавиши для любой программы (комбинация захватывается
  нажатием, а не вводится текстом).
- **Индикатор «открыто»** — по имени процесса, работает и для игр, которые
  стартуют через `steam://` или `com.epicgames.launcher://`.
- **Обратимость вместо подтверждений** — удаление программы, категории или
  набора происходит сразу и отменяется восемь секунд кнопкой в тосте.
- **Трей** — меню значка это мини-лаунчер: пять закреплённых программ с их
  комбинациями и «Открыть библиотеку», без открытия окна.
- **«Спокойный вид»** — один переключатель убирает счётчики, пути, мета-строки и
  полосу подсказок.

### Клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Пробел` | Показать или спрятать «Запуск» (комбинацию можно сменить) |
| `↑` / `↓` | Двигать выбор по списку |
| `Enter` | Запустить выбранное |
| `Ctrl+1`…`Ctrl+9` | Запустить закреплённое по номеру |
| `Ctrl+L` | «Библиотека» |
| `Ctrl+,` | «Настройки» |
| `Ctrl+K` | Поиск |
| `Ctrl+A` | Выбрать все видимые плитки |
| `Delete` | Убрать выбранное (обратимо 8 секунд) |
| `Ctrl+Enter` | Подтвердить добавление на экране «Найти и добавить» |
| `Esc` | Очистить запрос → закрыть поповер, экран, выбор → спрятать окно |

### Мышь

Клик по плитке выбирает её и открывает инспектор, двойной клик — запускает.
Когда что-то выбрано, у плиток появляется уголок-чекбокс: им набирается
множественный выбор. Клик по заголовку группы выбирает всю группу. Клик по
значку категории фильтрует, повторный клик по активной категории (а также
двойной клик и правая кнопка) открывает поповер с её цветом, иконкой и
удалением.

## Запуск из исходников

```bash
pip install -r requirements.txt
python main.py
```

Флаги и переменные окружения:

| | |
|---|---|
| `--hidden` | Старт свёрнутым в трей (используется автозапуском) |
| `--debug` или `CENTURIO_DEBUG=1` | Подробный лог в файл и в консоль |
| `CENTURIO_WEB=1`, `CENTURIO_PORT` | Открыть интерфейс в браузере вместо окна |

Веб-режим существует для отладки на не-Windows машине: трей, глобальные горячие
клавиши, автозапуск, размеры окна и поиск установленных программ в нём не
работают.

## Где лежат данные

Всё в `%APPDATA%\Centurio\`:

| Файл | Что это |
|---|---|
| `centurio-data.json` | Библиотека, категории, наборы, настройки |
| `icons\` | Кэш иконок и обложек |
| `centurio.log` | Лог (в режиме `--debug` или при включённом «Подробном логе») |
| `centurio-backup-*.json` | Резервные копии (кнопка в настройках) |
| `centurio-corrupt-*.json` | Карантин повреждённого файла данных |

Файл прошлой версии открывается как есть: новые поля (наборы, настройки режима
«Запуск») дописываются значениями по умолчанию.

## Тесты

```bash
python tests/test_centurio.py
```

Логика (хранилище, поиск приложений, запросы, цвета) проверяется на любой ОС и
без зависимостей; тесты интерфейса пропускаются, если Flet не установлен.

## Сборка Windows-инсталлятора

```bash
pip install "flet[all]==0.28.3"
python -m app.iconify                       # сгенерировать icon.png и tray.png
flet build windows -v                       # результат: build\windows\
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\centurio.iss
```

Готовый `installer\Output\CenturioSetup.exe` ставится без прав администратора и
предлагает создать ярлыки на рабочем столе и в автозапуске. То же самое делает
workflow **Build Windows installer** (вручную или по тегу `v*`).

Версия задаётся в `app/__init__.py`; `pyproject.toml` и `installer/centurio.iss`
должны совпадать с ней — это проверяется тестом.

## Диагностика

```bash
python -m app.diagnose
```

Печатает версию Python, состояние зависимостей, путь к файлу данных, результат
поиска приложений и найденные корни Steam — этот вывод удобно прикладывать к
сообщению о проблеме.

## Устройство

| Файл | За что отвечает |
|---|---|
| `app/colors.py` | Все цвета, размеры и радиусы — дизайн-токены |
| `app/view_state.py` | Состояние окна: режим, экран, запросы, выбор |
| `app/ui.py` | «Запуск», рельс, сетка, инспектор |
| `app/dialogs.py` | Поповер категории и экраны «Найти и добавить» / «Настройки» |
| `app/toast.py` | Сообщения и отмена действия |
| `app/queries.py` | Что показывать: списки, группы, предложение категории |
| `app/store.py` | Файл библиотеки, наборы, настройки, миграция |
| `app/discovery.py` | Поиск установленного, иконки, обложки |
| `app/main.py` | Окно, режимы, горячие клавиши, трей |
